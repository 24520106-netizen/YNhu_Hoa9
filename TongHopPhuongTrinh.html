Hệ Thống Tính Chất Hóa Học Của Kim Loại

Tổng hợp và phân loại logic toàn bộ phương trình hóa học từ tài liệu lý thuyết.

1. Tác Dụng Với Phi Kim

Tác dụng với oxygen ($O_2$)
Tạo oxide kim loại tương ứng; một số kim loại như Al, Zn, Cr tạo màng oxide bảo vệ ngay ở điều kiện thường.
  • $$3\text{Fe} + 2\text{O}_2 \xrightarrow{t^\circ} \text{Fe}_3\text{O}_4$$
  • $$4\text{Al} + 3\text{O}_2 \xrightarrow{t^\circ} 2\text{Al}_2\text{O}_3$$
  • $$2\text{Zn} + \text{O}_2 \xrightarrow{t^\circ} 2\text{ZnO}$$
  • $$2\text{Cu} + \text{O}_2 \xrightarrow{t^\circ} 2\text{CuO}$$
  • $$2\text{Mg} + \text{O}_2 \xrightarrow{t^\circ} 2\text{MgO}$$
  • $$2\text{Ca} + \text{O}_2 \xrightarrow{t^\circ} 2\text{CaO}$$
  • $$4\text{Cr} + 3\text{O}_2 \longrightarrow 2\text{Cr}_2\text{O}_3$$ (Tạo màng oxide mỏng, bền bảo vệ ở đk thường)
Tác dụng với chlorine ($\text{Cl}_2$)
Tạo muối chloride ở mức hóa trị cao nhất đối với kim loại đa hóa trị (như Fe tạo Fe(III)).
  • $$2\text{Na} + \text{Cl}_2 \xrightarrow{t^\circ} 2\text{NaCl}$$
  • $$2\text{Fe} + 3\text{Cl}_2 \xrightarrow{t^\circ} 2\text{FeCl}_3$$
  • $$\text{Cu} + \text{Cl}_2 \xrightarrow{t^\circ} \text{CuCl}_2$$
  • $$\text{Mg} + \text{Cl}_2 \xrightarrow{t^\circ} \text{MgCl}_2$$
  • $$\text{Zn} + \text{Cl}_2 \xrightarrow{t^\circ} \text{ZnCl}_2$$
  • $$2\text{Al} + 3\text{Cl}_2 \xrightarrow{t^\circ} 2\text{AlCl}_3$$
Tác dụng với lưu huỳnh / sulfur ($\text{S}$)
Tạo muối sulfide (Fe thể hiện mức hóa trị II).
  • $$2\text{Al} + 3\text{S} \xrightarrow{t^\circ} \text{Al}_2\text{S}_3$$
  • $$\text{Mg} + \text{S} \xrightarrow{t^\circ} \text{MgS}$$
  • $$\text{Zn} + \text{S} \xrightarrow{t^\circ} \text{ZnS}$$
  • $$\text{Fe} + \text{S} \xrightarrow{t^\circ} \text{FeS}$$
  • $$\text{Cu} + \text{S} \xrightarrow{t^\circ} \text{CuS}$$

2. Tác Dụng Với Nước ($\text{H}_2\text{O}$)

Ở nhiệt độ thường (Kim loại kiềm, kiềm thổ)
  • $$2\text{Na} + 2\text{H}_2\text{O} \longrightarrow 2\text{NaOH} + \text{H}_2 \uparrow$$
  • $$2\text{K} + 2\text{H}_2\text{O} \longrightarrow 2\text{KOH} + \text{H}_2 \uparrow$$
  • $$\text{Ca} + 2\text{H}_2\text{O} \longrightarrow \text{Ca(OH)}_2 + \text{H}_2 \uparrow$$
Ở nhiệt độ cao (Với hơi nước)
  • $$\text{Zn} + \text{H}_2\text{O} \xrightarrow{t^\circ} \text{ZnO} + \text{H}_2 \uparrow$$
  • $$3\text{Fe} + 4\text{H}_2\text{O} \xrightarrow{t^\circ < 570^\circ\text{C}} \text{Fe}_3\text{O}_4 + 4\text{H}_2 \uparrow$$
  • $$\text{Fe} + \text{H}_2\text{O} \xrightarrow{t^\circ > 570^\circ\text{C}} \text{FeO} + \text{H}_2 \uparrow$$

3. Tác Dụng Với Dung Dịch Acid (HCl)

Kim loại đứng trước Hydrogen trong dãy hoạt động hóa học phản ứng giải phóng khí $H_2$.
  • $$\text{Fe} + 2\text{HCl} \longrightarrow \text{FeCl}_2 + \text{H}_2 \uparrow$$
  • $$2\text{Al} + 6\text{HCl} \longrightarrow 2\text{AlCl}_3 + 3\text{H}_2 \uparrow$$
  • $$\text{Zn} + 2\text{HCl} \longrightarrow \text{ZnCl}_2 + \text{H}_2 \uparrow$$
  • $$\text{Mg} + 2\text{HCl} \longrightarrow \text{MgCl}_2 + \text{H}_2 \uparrow$$

4. Tác Dụng Với Dung Dịch Muối

Tác dụng với muối đồng ($\text{CuSO}_4, \text{CuCl}_2$)
  • $$\text{Fe} + \text{CuSO}_4 \longrightarrow \text{FeSO}_4 + \text{Cu} \downarrow$$
  • $$\text{Fe} + \text{CuCl}_2 \longrightarrow \text{FeCl}_2 + \text{Cu} \downarrow$$
  • $$\text{Mg} + \text{CuSO}_4 \longrightarrow \text{MgSO}_4 + \text{Cu} \downarrow$$
  • $$2\text{Al} + 3\text{CuSO}_4 \longrightarrow \text{Al}_2(\text{SO}_4)_3 + 3\text{Cu} \downarrow$$
  • $$\text{Zn} + \text{CuSO}_4 \longrightarrow \text{ZnSO}_4 + \text{Cu} \downarrow$$
Tác dụng với muối bạc ($\text{AgNO}_3$)
  • $$\text{Fe} + 2\text{AgNO}_3 \longrightarrow \text{Fe(NO}_3)_2 + 2\text{Ag} \downarrow$$
  • $$\text{Cu} + 2\text{AgNO}_3 \longrightarrow \text{Cu(NO}_3)_2 + 2\text{Ag} \downarrow$$
  • $$\text{Zn} + 2\text{AgNO}_3 \longrightarrow \text{Zn(NO}_3)_2 + 2\text{Ag} \downarrow$$
  • $$\text{Al} + 3\text{AgNO}_3 \longrightarrow \text{Al(NO}_3)_3 + 3\text{Ag} \downarrow$$
  • $$\text{Mg} + 2\text{AgNO}_3 \longrightarrow \text{Mg(NO}_3)_2 + 2\text{Ag} \downarrow$$
